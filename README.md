# SyncWatch
---
## How to use
Using it is very simple and easy, simply look up the anime using it's name and press on what every pops up. A window will appear with the ability to select the episode and weather you want it subbed or dubbed.

## How syncing works
Since it's meant for private occations away from the public internet, syncing happens as soon as one connects, after that all actions are now synced, from searching to playing and pausing.
